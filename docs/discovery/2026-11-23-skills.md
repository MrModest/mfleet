# Skills

Captured: 2026-11-23

## Context

The user's current setup: skills live in `~/.agents/skills`, and each
skill folder is automatically symlinked into `~/.claude/skills`.

The [home repo pattern](https://www.aihero.dev/the-home-repo-pattern)
recommends keeping skills in the home repo instead. The user doesn't
follow that part.

Skills also have to be present on every new host (see
[Connectors, credentials, and secrets](2026-11-23-connectors-credentials-and-secrets.md)).

## Ideas

Neither option is decided.

- `mfleet skills` as the way agents find and read skills, instead of the
  harness's built-in skill discovery. The user might delegate skills to it
  completely.

  ```
  mfleet skills search 'write for human'
  mfleet skills list
  ```

- `mfleet skills` as a plain skill manager:
  - skills are collected in `~/.config/mfleet/skills`;
  - `mfleet skills install humanise` symlinks the skill into the
    `.agents` and `.claude` folders in the home dir (global);
  - `mfleet skills install humanise --project` puts it into those folders
    in the project instead.
